# Crypto Trader

A Python-based cryptocurrency trading bot and learning project focused on exploring automated trading, market data, strategy development, backtesting, risk management, and trade execution.

This project is part of my ongoing journey to improve my **Python programming, software development, data handling, automation, and systems knowledge**.

> **Note:** This is an educational and experimental project. It is not intended to provide financial advice or guarantee profitable trading results.

---

## About the Project

I built this project to explore how an automated trading system can be structured and how different components work together.

Rather than treating the project as simply a "crypto bot", I'm using it to learn about the different technical problems involved in building an automated financial system.

These include:

- Market data
- Trading strategies
- Backtesting
- Risk management
- Trade execution
- Databases
- Alerts
- Logging
- Testing
- System diagnostics
- Automation

The project is still under development, and parts of the system may change as I learn and improve my understanding of automated trading systems.

## Project Structure

The repository is organised into several areas that represent different parts of the trading system.

**Main directories:**

- `alerts/` - Alerts and notifications
- `backtest/` - Backtesting functionality
- `backups/` - Project backups
- `config/` - Configuration
- `data/` - Market and application data
- `database/` - Database-related functionality
- `execution/` - Trade execution logic
- `reports/` - Reports and generated results
- `risk/` - Risk management functionality
- `scripts/` - Utility and automation scripts
- `strategies/` - Trading strategies
- `tests/` - Testing
- `utils/` - Shared utilities

**Main files:**

- `main_enhanced.py` - Main application entry point
- `pyproject.toml` - Python project configuration
- `requirements.txt` - Project dependencies
- `README.md` - Project documentation

## Key Areas

### Trading Strategies

The project contains a dedicated area for experimenting with trading strategies.

The purpose is to understand how trading rules can be translated into programmatic logic and evaluated using historical data.

I'm using this area to explore how different indicators, conditions, and rules can be combined to generate potential trading signals.

---

### Backtesting

Backtesting allows strategies to be evaluated against historical market data before considering live execution.

I'm using this part of the project to learn about:

- Historical data
- Strategy evaluation
- Trade simulation
- Performance analysis
- Backtest results
- Comparing different approaches

Backtesting is treated as an experimental tool rather than proof that a strategy will perform the same way in live markets.

---

### Risk Management

Risk management is an important component of the project.

The repository includes functionality for experimenting with:

- Risk presets
- Position sizing
- Trading limits
- Risk configuration
- Trade controls

The goal is to understand how risk can be incorporated into an automated trading system rather than focusing solely on generating trades.

---

### Trade Execution

The execution component explores how trading decisions can eventually be translated into executable orders.

This area is being developed with an emphasis on understanding:

- Order handling
- Execution logic
- Trading states
- Error handling
- Safety controls

The goal is to understand the technical challenges involved in moving from a trading signal to an actual order.

---

### Alerts & Monitoring

The project also includes alerting functionality to help monitor the system and identify important events.

This is useful for understanding how automated systems can communicate their state without requiring constant manual monitoring.

Monitoring and diagnostics are particularly important when working with systems that are designed to operate automatically.
