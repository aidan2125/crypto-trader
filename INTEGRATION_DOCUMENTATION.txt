2. BACKTEST RESULT PERSISTENCE
   File: database/supabase_db.py
   
   Function: insert_backtest_result(result: Dict) -> bool
   - Inserts backtest metrics into Supabase "backtests" table
   - Filters to only include valid schema columns
   - Handles foreign key constraints gracefully
   - Sets coin_id=NULL if coin doesn't exist in coins table
   - Returns True on success, False on failure
   
   Expected Fields:
   - preset_id (required): Foreign key to risk_presets
   - coin_id (optional): Foreign key to coins (set to NULL if missing)
   - run_time (required): ISO datetime string
   - timeframe: "1h", "4h", "1d", etc.
   - num_candles: Integer
   - num_trades: Integer
   - win_rate: Float (0.0-1.0)
   - profit_factor: Float
   - roi: Float (e.g., -0.052 for -5.2%)
   - max_drawdown: Float (e.g., -0.107)
   - avg_pnl: Float (average P&L per trade)
   - passed: Boolean (whether backtest met criteria)
   
   Usage:
   ```python
   from database.supabase_db import insert_backtest_result
   from datetime import datetime, timezone
   
   result = {
       "preset_id": 2,
       "coin_id": 1,
       "run_time": datetime.now(timezone.utc).isoformat(),
       "timeframe": "1h",
       "num_candles": 1000,
       "num_trades": 31,
       "win_rate": 0.387,
       "profit_factor": 0.77,
       "roi": -0.052,
       "max_drawdown": -0.107,
       "avg_pnl": -17,
       "passed": False
   }
   
   success = insert_backtest_result(result)
   if success:
       print("Backtest result saved to Supabase!")
   ```
   
   Status: ✓ IMPLEMENTED & TESTED

3. DATABASE SEEDING HELPER
   File: database/supabase_db.py
   
   Function: seed_coins(coin_list: list = None) -> bool
   - Populates the "coins" table with cryptocurrency symbols
   - Default coins: BTC/USDT, ETH/USDT, SOL/USDT
   - Gracefully handles duplicates (already existing coins)
   - Required to satisfy foreign key constraints in backtests table
   
   Usage:
   ```python
   from database.supabase_db import seed_coins
   
   # Use default coins
   seed_coins()
   
   # Or provide custom coins
   custom_coins = [
       {"symbol": "XRP/USDT", "base_currency": "XRP", "quote_currency": "USDT", "is_active": True},
       {"symbol": "ADA/USDT", "base_currency": "ADA", "quote_currency": "USDT", "is_active": True},
   ]
   seed_coins(custom_coins)
   ```
   
   Status: ✓ IMPLEMENTED & TESTED
